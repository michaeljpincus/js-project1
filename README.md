# The 2026 Atlas of the Newest New Yorkers

This is my first project in my *MUSA 6110: JavaScript Programming for Planners and Designers* course. This interactive web map displays data on foreign-born populations in select NYC neighborhoods reported in [*The Newest New Yorkers: A Statistical Portrait of Foreign-born Residents and Their Role in Shaping the City's Population*](https://www.nyc.gov/content/planning/pages/our-work/reports/newest-new-yorker), a 2026 report by the NYC Department of City Planning.

The map features interactive elements that display data on foreign-born demographics when a neighborhood is clicked on or selected from the drop-down menu.
